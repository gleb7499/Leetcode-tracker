## 📋 Описание

**LeetCode Tracker** — это прототип фронтенд-приложения для отслеживания решённых задач и организации интервальных повторений. Приложение помогает закреплять знания алгоритмов по методике spaced repetition.

### ✨ Основные возможности

- ✅ Добавление задач с LeetCode или собственных
- 📅 Планирование повторений на основе вашей оценки
- 📊 Просмотр задач, запланированных на сегодня
- 🔄 Последовательное повторение всех задач
- 💾 Локальное хранение данных (без сервера)
- 🌙 Тёмная тема по умолчанию
- ♿ Полная поддержка доступности (a11y)
- ⌨️ Клавиатурная навигация

## 📱 Экраны приложения

### 1. Главная страница

Отображает список задач на сегодня:
- Карточки с названием, сложностью, темами
- Кнопки "Решить" и "Удалить"
- Кнопка "Повторить все"

### 2. Добавление задачи

Форма с полями:
- **Ссылка на задачу** (обязательно, валидация URL)
- **Название** (обязательно, 3–200 символов)
- **Сложность** (Easy/Medium/Hard)
- **Темы** (через запятую)
- **Заметки** (необязательно)

Форма включает:
- HTML5-валидацию
- Валидацию в реальном времени
- Визуальную индикацию ошибок
- Сообщения об успехе

### 3. Повторение задачи

Карточка задачи с тремя кнопками оценки:
- ❌ **Don't Remember** → повтор через 1 день
- ⚠️ **Partially Remember** → повтор через 3 дня
- ✅ **Remember Well** → повтор через 7 дней

### 4. Статистика (в разработке)

Заглушка для будущего функционала.

### 5. Настройки (в разработке)

## ♿ Доступность (a11y)

Приложение разработано с учётом стандартов **WCAG 2.1 AA**:

### Реализованные возможности:

✅ **Семантический HTML**
- Корректная иерархия заголовков (`h1` → `h2` → `h3`)
- Использование `<main>`, `<nav>`, `<article>`, `<section>`
- `role` атрибуты для уточнения семантики

✅ **ARIA-атрибуты**
- `aria-label`, `aria-labelledby`
- `aria-current` для активной навигации
- `aria-live` для динамического контента
- `aria-describedby` для подсказок
- `aria-invalid` для ошибок форм

✅ **Клавиатурная навигация**
- Все элементы доступны через `Tab`
- Видимый фокус (`:focus-visible`)
- Горячие клавиши: `Esc`, `Alt+1–4`

✅ **Контрастность**
- Соотношение контраста ≥ 4.5:1
- Тёмная тема с читаемыми цветами

✅ **Формы**
- Все `<input>` имеют `<label>`
- Сообщения об ошибках связаны с полями
- Обязательные поля помечены визуально и семантически

✅ **Скринридеры**
- Понятные `aria-label` для всех интерактивных элементов
- Анонсы изменений через `aria-live`

### Тестирование доступности

Рекомендуемые инструменты:
- **Lighthouse** (в Chrome DevTools) — цель: ≥90 баллов
- **axe DevTools** (расширение для браузера)
- **NVDA / JAWS** (скринридеры)

## 📐 Адаптивный дизайн

Приложение адаптировано под **три брейкпоинта**:

| Разрешение | Особенности |
|------------|-------------|
| ≤600px (мобильный) | Вертикальная навигация внизу, одноколоночный список |
| 601–1024px (планшет) | Горизонтальная навигация сверху, сетка карточек |
| >1024px (десктоп) | Боковая навигация слева, Grid-сетка для задач |

### Mobile-first подход

Стили написаны с использованием **mobile-first** методологии:
- Базовые стили для мобильных
- `@media (min-width: ...)` для более крупных экранов

## 💾 Хранение данных

Приложение использует **localStorage** браузера:

```javascript
// Ключ хранения
localStorage.getItem('leetcode-tracker-tasks')

// Формат данных
{
  id: "task-1234567890-abc123",
  name: "Two Sum",
  url: "https://leetcode.com/problems/two-sum/",
  difficulty: "Easy",
  topics: ["Array", "Hash Table"],
  notes: "Используем HashMap для O(n)",
  createdAt: "2025-10-22T10:00:00.000Z",
  nextReview: "2025-10-23T10:00:00.000Z",
  reviews: [
    {
      date: "2025-10-22T10:00:00.000Z",
      status: "remember"
    }
  ]
}
```

### Демо-данные

При первом запуске приложение создаёт **3 демо-задачи**:
1. Two Sum (Easy)
2. Add Two Numbers (Medium)
3. Median of Two Sorted Arrays (Hard)

Вы можете удалить их и добавить свои.

## 🎨 Кастомизация

### Изменение цветовой схемы

Все цвета вынесены в CSS-переменные в `:root`:

```css
:root {
  --color-bg-primary: #121212;
  --color-text-primary: #e0e0e0;
  --color-accent: #3bc9db;
  /* ... и другие */
}
```

Вы можете легко изменить тему, отредактировав эти переменные.

### Добавление светлой темы

Раскомментируйте и доработайте блок:

```css
@media (prefers-color-scheme: light) {
  :root {
    --color-bg-primary: #ffffff;
    /* ... */
  }
}
```
