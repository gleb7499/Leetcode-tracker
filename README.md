# Leetcode Tracker

Leetcode Tracker — проект для интервального повторения задач по алгоритмам и отслеживания прогресса обучения.

## Стек проекта

- Frontend: React + Vite + TypeScript
- Backend: Java + Spring
- База данных: PostgreSQL

## Быстрый старт (frontend)

```bash
cd frontend
npm install
npm run dev
```
